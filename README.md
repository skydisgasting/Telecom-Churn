## 📌 О чём этот проект?

Это end-to-end решение для прогнозирования оттока (churn prediction) клиентов телеком-компании. Модель машинного обучения идентифицирует клиентов с высоким риском ухода за **3 месяца** до фактического оттока, что позволяет службе удержания запускать точечные и проактивные кампании.

---

## 🎯 Ключевые результаты

*   **Точность (Accuracy): 80%** на целевом классе ("уйдет") — означает, что из всех клиентов, которых модель пометила как "уходящих", 80% действительно собирались уйти. Это **снизило долю ложных срабатываний** и позволило сфокусировать ресуры на реальных угрозах.
*   **Полнота (Recall): 76%** — означает, что модель смогла correctly идентифицировать 76% всех клиентов, которые в итоге ушли. Это позволяет охватить подавляющее большинство "уходящих".
*   **Бизнес-эффект:** Модель таргетирует **15% клиентской базы** с наивысшим риском, позволяя экономить **до 25 млн рублей ежегодно** за счет снижения затрат на привлечение новых клиентов взамен ушедших.

---

## 🛠️ Технологии и методы

**Машинное обучение:**
*   `Python 3`, `Pandas`, `NumPy`, `Scikit-learn`, `XGBoost`, `Imbalanced-learn`
*   **Ансамбли моделей:** Комбинация `XGBoost` и `Random Forest` для увеличения robustness и точности предсказаний.
*   **Борьба с дисбалансом классов:** Применен метод **SMOTE** (Synthetic Minority Over-sampling Technique) для генерации синтетических примеров минорного класса (уходящие клиенты).
*   **Этапы работы пайплайна:** Предобработка данных, Feature Engineering, Кросс-валидация, Подбор гиперпараметров (GridSearch/RandomizedSearch), Оценка и интерпретация модели.

**Обработка данных:**
*   Обработано **10,000+** записей клиентов.
*   Проанализировано **50+** признаков, включая:
    *   **Демографические данные**
    *   **Паттерны использования услуг** (длительность звонков, трафик интернета)
    *   **История платежей** (средний чек, регулярность оплат, наличие долга)
    *   **История взаимодействия с поддержкой** (количество обращений, жалоб)
